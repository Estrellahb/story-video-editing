# 故事视频剪辑工作流

可复用的 Codex 技能：收到未剪辑素材后，确认剪辑风格、素材起止范围、目标时长与故事链，再完成剪辑和发布素材交付。

## 流程

确认需求 → 梳理素材 → 确认故事链 → 剪辑与字幕 → 导出检查 → 五件交付 → 选择上传平台。

保持故事完整、因果清楚和结尾完整，保留必要铺垫及朋友原声互动。

## 默认规格

- 横版 16:9，1920×1080，60 fps。
- 白色对白字幕，思源黑体简体中文 Bold，字号 48，#009AFF 描边 3 像素。
- 成片只保留对白字幕，不添加段落标题、标注标题、开场片名或搞笑旁注。
- 视频沿用原素材的封装格式及扩展名。
- 每个视频交付：视频、SRT、TXT、16:9 封面和 4:3 封面。
- TXT 包含视频标题、纯文字标签、简介；简介包含朋友名字和“剪辑GPT”，整体不超过 100 字。
- 默认上传平台为 B站；实际上传按用户当次指令执行。

SRT 只携带文字和时间码；指定的字体和描边样式烧录在视频中。

## 使用

将 `skills/story-video-editing` 文件夹放入个人 Codex skills 目录，然后调用：

```text
使用 $story-video-editing 处理这段未剪辑素材，先确认风格、起止范围、目标时长和故事链。
```

完整技能说明见 [SKILL.md](skills/story-video-editing/SKILL.md)。其中本机资源路径仅供现有环境复用；其他机器使用自己的素材、工作目录和字体路径。

仓库保存工作流说明与技能元数据；字体、视频素材、模型和成片需在使用时另行准备。
